# jsconf-fiber-unplugged

Talk materials for **"React Fiber Unplugged: How the Internal Scheduler Shapes React"** by Saman Abbasi — JSConf JP 2026, Tokyo (22 Nov 2026, Track A).

- `CLAIMS.md` — every technical claim, verified against React **19.3.1** source (tag `v19.3.1`) with line links
- `OUTLINE.md` — slide-by-slide outline with timings and claim references
- `PROGRESS.md` — short notes after each phase
- `verification/` — reproducible empirical checks against the npm builds in headless Chromium (`npm i && npm run verify`)
- `source-material/how-react-works/` — the 9-part "How React Works" series (base material)
- `source-material/CLAIMS.draft.md` — earlier draft of the verification notes (superseded by `CLAIMS.md`)
