# Boss-room sprites (drawn in code, no image generation)

All sprites are true pixel art at 1× size. Display them at **×12**, integer scaling only,
`image-rendering: pixelated`. Generated by the Python scripts in `src/` (PIL), so they can be
regenerated or tweaked. No AI image model was used.

## Layout these were checked with (see scenes.png)
- Arena: full width during the fight, 1860×760, ground y = 690 (the two big HUD numbers move to a slim top bar).
- Castle at x≈20 (≈408 px wide), goblins in front of it, Fiber-kun (16×16 at ×12 = 192 px) at x≈600.
- Dragon right-aligned (≈10 px margin), feet on the ground (baseline_row).
- Breath: put `anchor_mouth` of `ice_breath_down` on the breath pose's `mouth`. The breath pose's head is tilted 19.4° and the cone is 19.6°, so it hits Fiber-kun's centre at x≈600. If Fiber-kun moves, regenerate the cone with the new angle (`src/ice_angle.py`, one parameter).
- Scale bible (update the test): dragon ≈ 63% of arena height, Fiber-kun 25%, goblin ≈ 20% (made bigger so it is readable), castle ≈ 36% (≈ 43% with flames).

## Notes
- The dragon has volume shading (rim light, mid, core shadow), a dark-red selective outline on lit top edges, and a subtle scale texture. Defeated = lying on its belly with dizzy stars.
- scenes.png uses a Fiber-kun rebuilt from a screenshot ONLY for the preview; use the real Fiber-kun sprite from the deck.
