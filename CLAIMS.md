## B. Yield vs interrupt

| # | Claim | Status | Evidence |
|---|---|---|---|
| B1 | **Yield** = pause. When `shouldYield()` is true the loop exits, `workInProgress` stays where it is, and the Scheduler task returns a continuation. The next slice continues from the same fiber: same root and same lanes, so there is no `prepareFreshStack`. | ✅ S E | [`renderRootConcurrent` #L2785-L2814](https://github.com/facebook/react/blob/v19.3.1/packages/react-reconciler/src/ReactFiberWorkLoop.js#L2785-L2814) ("This is a continuation of an existing work-in-progress"); continuation returned at [ReactFiberRootScheduler.js#L603](https://github.com/facebook/react/blob/v19.3.1/packages/react-reconciler/src/ReactFiberRootScheduler.js#L603). **E:** a 1,500-row transition with 40+ yields rendered each row exactly once. |
| B2 | **Interrupt** = throw away and restart. If React next renders a different root or **different lanes**, it calls `prepareFreshStack`, and the half-built tree is discarded. Once the urgent work commits, the transition starts again **from the root**. | ✅ S E | [renderRootSync #L2635-L2653](https://github.com/facebook/react/blob/v19.3.1/packages/react-reconciler/src/ReactFiberWorkLoop.js#L2635-L2653), [renderRootConcurrent #L2787-L2807](https://github.com/facebook/react/blob/v19.3.1/packages/react-reconciler/src/ReactFiberWorkLoop.js#L2787-L2807). **E:** a click at row 288 commits the urgent state first, then the transition renders 1,500 rows again (total 1,788; the first 288 were wasted). |

There is an explicit rule: **a Default update does not interrupt a transition.** Sync (click, key) and InputContinuous (scroll, mousemove) do interrupt. | ✅ S E ⚠️ | [ReactFiberLane.js#L334-L357](https://github.com/facebook/react/blob/v19.3.1/packages/react-reconciler/src/ReactFiberLane.js#L334-L357); comment in [`getEntangledLanes` #L430-L435](https://github.com/facebook/react/blob/v19.3.1/packages/react-reconciler/src/ReactFiberLane.js#L430-L435): "continuous updates should interrupt transitions, but default updates should not". **E:** a `setTimeout` update at row 247: the transition commits first (1,500 rows, no restart), then the Default update. |

That is not how it works: React picks lanes **for the whole root**, starts from the root, and skips subtrees that have no work in those lanes. | ✏️ | [`getNextLanes`](https://github.com/facebook/react/blob/v19.3.1/packages/react-reconciler/src/ReactFiberLane.js#L249) works on `root.pendingLanes`; C1 below. |
| B5 | ⚠️ New in 19.x: `enableParallelTransitions = true`. Different transitions can get separate lanes, but transitions that update the **same state hook are entangled** and render together. ## K. The boss fight: what each game element stands for
